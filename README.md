## 📖 How to Use

### Creating Your First Board
1. Open colosseum
2. Click the "+" button to create a new board
3. Give your board a name and description
4. Start adding items by clicking the "+" button

### Adding Items
- **Images:** Drag and drop images from your computer or paste an image URL
- **Videos:** Paste a video link from YouTube, Vimeo, or other sites
- **Links:** Paste any web URL to save it
- **Text:** Write notes or paste text snippets

### Organizing Your Collection
- **Rename boards** by double-clicking the board title
- **Reorder items** by dragging them
- **Delete items** by right-clicking and selecting "Delete"
- **Search boards** using the search bar at the top

## 🔧 Troubleshooting

### Common Issues

**App won't open**
- Make sure you're running macOS 14.0 or later
- Try downloading the latest version again
- Restart your Mac and try again

**Items not saving**
- Check your storage space is not full
- Make sure you have write permissions to the app's folder

**Boards not showing**
- Try restarting the app
- Check the app's menu for "Show All Boards"

**Search not working**
- Make sure you're typing in the search field
- Try clearing the search and typing again
